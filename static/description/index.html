Elks Investigation Workspace

FCRA-aware membership-applicant background investigations for Elks Lodges, built on top of elkscontacts.

What you get

📋 Ticket-style worklist

Each committee member opens "My Investigations" and sees applications assigned to them, plus any unassigned ones they can claim. First-click claim, no chair-staging needed.

🔍 One-screen workspace

10-year residential and employment history, references, per-jurisdiction background checks, and a cross-check engine — all on one tab inside the existing Membership Application form.

⚡ Automated OFAC SDN screen

Downloads the official Treasury Specially Designated Nationals CSV and searches ~7,500 listed individuals locally against the applicant name + aliases. Zero operator effort on clean matches.

📑 Bulk paste-and-parse

Operator pastes the result block from any court portal — wizard extracts one Hit row per record with court, role (Defendant/Plaintiff/Respondent/Judgment Debtor), case #, and date. Works on WA, ID iCourt, and most tabular portal copy-pastes.

🚦 Cross-check engine

Automatically flags state-coverage gaps, name/DOB mismatches, county-mismatch when the applicant didn't disclose presence there, and demotes Plaintiff hits to context. Severity-graded HIGH / MEDIUM / LOW / INFO.

📄 Two report formats

1-page summary report (PDF) as default — colored coverage strip, jurisdictions checked, high-severity flags only, sign-off line. Multi-page detailed report and Word (.docx) available too.

Roles & permissions

Two new roles in the Elks Lodge privilege block:

Role Can do
Investigation Committee Member Claim unassigned investigations, work assigned ones, capture findings, submit ACCEPT/DENY recommendations. Restricted by record rule: can only see own + unassigned active investigations.
Investigation Chairman Secretary-equivalent. Sees all investigations, manages the Portal Directory, overrides assignments and recommendations.
Lodge Secretary (existing) Backup access — Secretary already has full write/create on all investigation models so the workflow keeps moving even when committee members aren't around.

Manage assignments from Investigations → Configuration → User Roles & Permissions.

What this module does NOT do

It does not scrape state court portals, NSOPW, or other government records sites. Those sites' terms of service prohibit automated access, and producing fully automated consumer reports for membership-eligibility decisions would turn the Lodge into a "consumer reporting agency" under the federal Fair Credit Reporting Act. Only OFAC's published CSV is fully automated, because Treasury distributes it specifically for this purpose.

For paid, FCRA-compliant fully-automated nationwide screening, the recommended path is a licensed Consumer Reporting Agency (Checkr, Sterling, GoodHire, etc.). A CRA-supplied report can be transcribed into this tool's per-jurisdiction prompts.
